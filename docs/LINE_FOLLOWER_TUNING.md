# TASK1 巡线速度调节说明

## 1. 参数位置与单位

TASK1 调用 `LineFollower_Start()` 启动巡线。速度和停车标志参数位于
`Drivers/DRV8870/Inc/line_follower.h`。

速度参数的单位不是 PWM 百分比，而是每个控制周期的编码器计数。当前控制周期由
`LINE_FOLLOW_CONTROL_PERIOD_MS` 定义为 1 ms，因此：

```text
编码器计数/秒 = 速度参数 × 1000
```

实际线速度还与轮径和每圈编码器计数有关：

```text
线速度 = 速度参数 × 1000 × 车轮周长 / 每圈编码器计数
```

## 2. 主要速度参数

| 参数 | 作用 | 调节原则 |
| --- | --- | --- |
| `LINE_FOLLOW_BASE_SPEED_TICKS` | 直线巡航目标速度 | 提速时优先增加 |
| `LINE_FOLLOW_MAX_SPEED_TICKS` | 单轮目标速度绝对值上限 | 必须高于基础速度，并为转向留出余量 |
| `LINE_FOLLOW_SIDE_MIN_STEERING_TICKS` | 仅侧边传感器识别黑线时的最低纠偏量 | 转向响应过弱时适当增加 |
| `LINE_FOLLOW_TEST_PWM_LIMIT` | 速度 PID 的最大 PWM 输出 | 实际范围为 0～1000，逐步增加 |

转向 PID 不再设置独立的最大修正量。其有效范围根据基础速度和单轮最大速度自动
推导，最终左右轮目标仍限制在 `±LINE_FOLLOW_MAX_SPEED_TICKS`，因此不会向速度环
发送超范围目标。

## 3. 推荐提速档位

以下数值用于逐级实车测试，不应直接从低速跳到最高档：

| 档位 | 基础速度 | 最大速度 | PWM 上限 |
| --- | ---: | ---: | ---: |
| 低速验证 | `0.50F` | `0.70F` | `300.0F` |
| 中速 | `0.60F` | `0.90F` | `400.0F` |
| 较高速 | `0.75F` | `1.10F` | `500.0F` |
| 高速试验 | `0.90F` | `1.30F` | `600.0F` |

每次只提升一个档位。第一次使用新档位时先架空驱动轮，确认两个编码器方向、
左右轮转向和制动逻辑正确，再落地测试。

## 4. 调试观察量

通过 `LineFollower_GetState()` 返回的状态观察：

| 字段 | 含义 |
| --- | --- |
| `left_target_speed` / `right_target_speed` | 速度环的左右轮目标 |
| `left_encoder_delta` / `right_encoder_delta` | 当前 1 ms 内的编码器计数 |
| `left_pwm` / `right_pwm` | 速度 PID 最终输出 |
| `line_position` | 当前黑线位置误差 |
| `gray_active_mask` / `gray_active_count` | 检测到黑线的传感器和数量 |
| `gray_invalid_cycles` | 非连续异常灰度模式持续的帧数 |
| `stop_marker_cycles` | 连续三路或全部四路为黑线持续的帧数 |

根据现象调整：

- PWM 长时间达到上限，但编码器速度仍低于目标：逐步提高
  `LINE_FOLLOW_TEST_PWM_LIMIT`，并检查电池、电机负载和机械阻力。
- 实际速度已经跟随目标，但直线速度仍低：同时提高基础速度和最大速度。
- 高速时转不过弯：提高转向 Kp；若仅侧边传感器触发时响应过弱，再提高
  `LINE_FOLLOW_SIDE_MIN_STEERING_TICKS`。
- 高速时左右摆动：先降低转向 Kp；由于灰度位置是离散信号，Kd 过大也可能放大跳变。
- 左右轮速度剧烈波动：再调整速度 Kp/Ki，不要把速度 PID 作为第一项提速参数。

## 5. PID 与 EEPROM

`LINE_FOLLOW_STEERING_*` 和 `LINE_FOLLOW_SPEED_*` 是 PID 默认值。系统启动时会优先
从 EEPROM 加载已保存参数，因此只修改头文件中的 PID 默认值不一定立即生效。

当前四路灰度位置误差为 `0、±1000、±2000、±3000`。建议从以下转向环参数开始：

```c
#define LINE_FOLLOW_STEERING_KP 0.00045F
#define LINE_FOLLOW_STEERING_KI 0.0F
#define LINE_FOLLOW_STEERING_KD 0.000003F
```

该 Kp 在误差为 `1000、2000、3000` 时分别产生约 `0.45、0.90、1.35` 的速度修正。
结合当前 `1.35` 的基础速度和 `2.00` 的单轮速度上限，可作为实车起调值。

建议调节范围：

| 参数 | 建议起点 | 常用试调范围 | 每次调整 |
| --- | ---: | ---: | ---: |
| 转向 Kp | `0.00045` | `0.00030～0.00070` | `0.00005` |
| 转向 Kd | `0.000003` | `0～0.000008` | `0.000001` |
| 转向 Ki | `0` | 保持为 `0` | 暂不调整 |

调节时先把 Kd 设为 `0`，只增加 Kp：

- 弯道进入太迟、经常扫到最外侧传感器：逐步增加 Kp；
- 直线左右蛇形摆动、`L2/L1` 快速来回跳变：Kp 过大，回退约 15%～25%；
- 找到刚开始轻微摆动的 Kp 后略微回退，再开始增加 Kd；
- Kd 合适时，入弯和出弯后的过冲会减小；
- 电机目标速度在灰度状态切换时突然跳变、车身抖动或出现高频摆动：Kd 过大。

由于控制周期为 1 ms，且灰度误差按 `1000` 为一级跳变，Kd 对离散状态切换非常敏感，
一般不建议超过 `0.000010`。

可以通过 ESP32 协议：

- 使用 `TURN` 或 `SPEED` 命令直接调节并保存 PID；
- 修改默认值并重新烧录后，发送 `DEFAULT`，将新的默认 PID 写入 EEPROM；
- 使用 `GET` 检查当前实际运行参数。

基础速度、速度上限、侧边最低纠偏量和 PWM 上限不是 EEPROM 参数，修改后需要重新
编译并烧录 STM32 固件。

## 6. 停车标志

当前四路灰度传感器从左到右为 `L3、L2、L1、M`，中心位于 `L2` 和 `L1` 之间。
TASK1 仅将连续的左三路、右三路或全部四路识别为停车标志。

灰度输入为低电平有效：GPIO 为 `0` 表示黑线，GPIO 为 `1` 表示白色背景。
`gray_active_mask` 会将有效状态转换为 `1`，其 bit3..bit0 固定对应
`M、L1、L2、L3`。

现有板卡接线和 CubeMX 历史信号标签并不一致，循迹模块按以下关系读取：

| 实物位置 | 当前 GPIO 标签 |
| --- | --- |
| `L3` | `L1_Pin` |
| `L2` | `M_Pin` |
| `L1` | `L2_Pin` |
| `M` | `L3_Pin` |

当前控制周期为 1 ms，`LINE_FOLLOW_STOP_MARKER_CYCLES` 为 5，因此 `0111`、
`1110` 或 `1111` 连续 5 帧约为 5 ms 时触发停车。任意一帧不属于这三种状态都会
清零计数；达到阈值后，左右电机立即进入 DRV8870 制动状态。

由于本题赛道没有岔路，正常黑线状态必须是连续的传感器组合。`0101`、`1001`、
`1010`、`1011` 和 `1101` 被视为异常模式，不进入位置 PID，也不触发停车标志。
异常短于 `LINE_FOLLOW_INVALID_HOLD_MS` 时保持最后一次有效轮速；持续超过该时间后
按丢线累计，最终使用 `LINE_FOLLOW_LOST_STOP_MS` 阈值停车。只有重新检测到合法的
连续黑线模式才会清除异常和丢线计数。

高速时停车距离主要由车速、轮胎附着力和车辆惯性决定。减小确认帧数只能缩短识别延迟，
不能消除机械制动距离。

## 7. 调节顺序

建议按以下顺序调节：

1. 保持 1 ms 控制周期不变。
2. 提高基础速度。
3. 根据目标车速同步提高最大速度。
4. PWM 饱和且实际速度不足时，再提高 PWM 上限。
5. 根据弯道表现调整转向 Kp 和侧边最低纠偏量。
6. 最后根据振荡、跟随误差调整转向 PID 和速度 PID。
