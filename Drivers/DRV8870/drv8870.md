# DRV8870 驱动使用说明

## 1. 功能概述

本模块使用 STM32 HAL 定时器 PWM 控制 DRV8870 双向直流电机驱动器。

驱动采用慢衰减模式：

| 工作状态 | IN1 | IN2 |
| --- | --- | --- |
| 正转驱动 | 1 | 0 |
| 反转驱动 | 0 | 1 |
| 慢衰减/制动 | 1 | 1 |
| 滑行/休眠 | 0 | 0 |

调速时，一个输入保持高电平，另一个输入在驱动状态和 `11` 制动状态之间切换。因此 PWM 关断阶段为低侧慢衰减，而不是 `00` 快衰减。

## 2. 工程文件

```text
Drivers/DRV8870/
├── Inc/drv8870.h
├── Src/drv8870.c
└── drv8870.md
```

驱动不直接引用 `main.h` 或工程中的全局定时器变量。应用层在初始化时传入定时器句柄和两个 PWM 通道，因此同一模块可以创建多个电机实例。

## 3. 使用前配置

每个 DRV8870 需要两个属于同一定时器的 PWM 通道：

1. 将 IN1、IN2 引脚配置为定时器复用推挽输出。
2. 两个通道均配置为 PWM Generation、PWM mode 1、高电平有效。
3. 两个通道使用相同的计数周期。
4. 先调用 CubeMX 生成的定时器初始化函数，再调用 `DRV8870_Init()`。

当前工程配置如下：

| 电机 | IN1 | IN2 | 定时器 |
| --- | --- | --- | --- |
| Motor 1 | PA2 / TIM15_CH1 | PA3 / TIM15_CH2 | TIM15 |
| Motor 2 | PF11 / TIM24_CH1 | PF12 / TIM24_CH2 | TIM24 |

TIM15 和 TIM24 的定时器时钟为 275 MHz，当前使用 `PSC = 0`、`ARR = 13749`，PWM 频率为 20 kHz。

## 4. API 说明

### `DRV8870_Init`

```c
DRV8870_StatusTypeDef DRV8870_Init(
    DRV8870_HandleTypeDef *driver,
    TIM_HandleTypeDef *timer,
    uint32_t in1_channel,
    uint32_t in2_channel);
```

初始化一个驱动实例并启动两个 PWM 通道。

- `driver`：由应用层分配的驱动句柄。
- `timer`：已经完成初始化的 HAL 定时器句柄。
- `in1_channel`：连接 DRV8870 IN1 的定时器通道。
- `in2_channel`：连接 DRV8870 IN2 的定时器通道。
- 初始化成功后默认进入制动状态，电机不会自动转动。
- 两个通道依次启动期间保持 `00`，避免上电瞬间误驱动。

### `DRV8870_SetSpeed`

```c
DRV8870_StatusTypeDef DRV8870_SetSpeed(
    DRV8870_HandleTypeDef *driver,
    int16_t speed);
```

设置电机方向和占空比，参数范围为 `-1000` 到 `1000`。

| 参数示例 | 作用 |
| --- | --- |
| `1000` | 正转，100% 输出 |
| `500` | 正转，50% 输出 |
| `0` | 制动 |
| `-500` | 反转，50% 输出 |
| `-1000` | 反转，100% 输出 |

超出范围时返回 `DRV8870_ERROR_PARAMETER`，不会改变当前输出。正负方向取决于电机接线；若机械方向与预期相反，可以交换电机线或对速度指令取反。

### `DRV8870_Brake`

```c
DRV8870_StatusTypeDef DRV8870_Brake(
    DRV8870_HandleTypeDef *driver);
```

令 IN1、IN2 同时为高电平，进入低侧制动状态，并将句柄中的速度记录为 0。

### `DRV8870_Coast`

```c
DRV8870_StatusTypeDef DRV8870_Coast(
    DRV8870_HandleTypeDef *driver);
```

令 IN1、IN2 同时为低电平，使 H 桥输出高阻，电机自由滑行。DRV8870 持续处于该状态约 1 ms 后会进入低功耗休眠。

### `DRV8870_DeInit`

```c
DRV8870_StatusTypeDef DRV8870_DeInit(
    DRV8870_HandleTypeDef *driver);
```

先进入滑行状态，再停止两个 PWM 通道，并将实例标记为未初始化。重新使用前必须再次调用 `DRV8870_Init()`。

## 5. 返回值

| 返回值 | 含义 |
| --- | --- |
| `DRV8870_OK` | 操作成功 |
| `DRV8870_ERROR_PARAMETER` | 空指针、通道错误、速度越界或定时器周期无效 |
| `DRV8870_ERROR_NOT_INITIALIZED` | 实例尚未初始化或已经反初始化 |
| `DRV8870_ERROR_HAL` | HAL PWM 启动或停止失败 |

建议检查初始化返回值。运行期间的控制接口也可以根据应用的故障处理策略检查返回值。

## 6. 双电机使用示例

```c
#include "drv8870.h"
#include "tim.h"

static DRV8870_HandleTypeDef motor1;
static DRV8870_HandleTypeDef motor2;

static void Motor_Init(void)
{
  if (DRV8870_Init(&motor1, &htim15,
                   TIM_CHANNEL_1, TIM_CHANNEL_2) != DRV8870_OK)
  {
    Error_Handler();
  }

  if (DRV8870_Init(&motor2, &htim24,
                   TIM_CHANNEL_1, TIM_CHANNEL_2) != DRV8870_OK)
  {
    Error_Handler();
  }
}
```

必须在 `MX_TIM15_Init()`、`MX_TIM24_Init()` 之后调用 `Motor_Init()`。

```c
/* 电机 1 正转 60%，电机 2 反转 40%。 */
(void)DRV8870_SetSpeed(&motor1, 600);
(void)DRV8870_SetSpeed(&motor2, -400);

/* 电机 1 制动，电机 2 自由滑行。 */
(void)DRV8870_Brake(&motor1);
(void)DRV8870_Coast(&motor2);
```

## 7. 注意事项

- `DRV8870_SetSpeed(0)` 的行为是制动；需要自由滑行时应显式调用 `DRV8870_Coast()`。
- 不要在多个执行上下文中同时操作同一个驱动句柄；如需在中断和主循环中共同控制，应由应用层增加临界区或统一消息入口。
- 本模块只负责方向、PWM 调速、制动和滑行，不包含编码器闭环、加减速斜坡或电流调节。
- DRV8870 的限流值由 VREF 和 ISEN 外部电路决定，不由本软件模块配置。
